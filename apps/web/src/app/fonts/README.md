# Licensed font files

Place the licensed Galaxie Copernicus webfonts in this folder before replacing the temporary local-font lookup in `../globals.css` with `next/font/local` in `../layout.tsx`.

Expected files:

- `GalaxieCopernicus-Book.woff2`
- `GalaxieCopernicus-BookItalic.woff2`
- `GalaxieCopernicus-Semibold.woff2`

Do not commit these files to a public repository unless the license explicitly permits redistribution.
